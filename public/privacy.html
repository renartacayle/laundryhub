Kebijakan Privasi LAUNDRYHUB

Terakhir diperbarui: 3 Oktober 2026

Selamat datang di LAUNDRYHUB ("Aplikasi", "Kami"). Kami berkomitmen untuk melindungi privasi Anda dan memastikan data transaksi bisnis laundry Anda aman. Kebijakan Privasi ini menjelaskan bagaimana kami mengumpulkan, menggunakan, dan melindungi informasi Anda saat menggunakan aplikasi mobile dan layanan web LAUNDRYHUB.

1. Informasi yang Kami Kumpulkan

Kami mengumpulkan informasi yang diperlukan untuk mengoperasikan fungsi kasir Point of Sale (POS) dan manajemen laundry:

  • Data Profil Bisnis: Nama outlet laundry, alamat, nomor telepon/WhatsApp, dan nama kasir/owner.
  • Data Transaksi: Nomor nota, rincian pakaian, berat/jumlah cucian, nama & nomor telepon pelanggan, dan status pembayaran.
  • Data Perangkat & Diagnostik: Model perangkat, versi sistem operasi Android, dan log crash anonim untuk meningkatkan stabilitas sistem.

2. Izin Perangkat (Android Device Permissions)

Aplikasi memerlukan izin perangkat tertentu untuk menjalankan fungsi operasional:

  • Kamera (CAMERA): Digunakan khusus untuk memindai QR Code invoice atau kode QR pelacakan pakaian cucian. Kami TIDAK menyimpan atau merekam foto wajah pengguna.
  • Bluetooth (BLUETOOTH, BLUETOOTH_CONNECT, BLUETOOTH_SCAN): Digunakan untuk menghubungkan aplikasi ke printer thermal struk mini (58mm / 80mm ESC/POS) secara nirkabel saat mencetak nota kasir.
  • Akses Internet (INTERNET, ACCESS_NETWORK_STATE): Digunakan untuk sinkronisasi data cloud real-time, verifikasi QRIS dinamis, dan pengiriman notifikasi WhatsApp.
  • Getaran (VIBRATE): Memberikan feedback getar saat pemindaian barcode/QR berhasil.

3. Penggunaan & Keamanan Informasi

Kami menerapkan standar enkripsi transit (HTTPS / TLS 1.3) dan enkripsi data lokal. Data Anda digunakan semata-mata untuk:

  • Menyediakan layanan operasional kasir laundry dan pelacakan cucian pelanggan.
  • Mencetak struk pembayaran secara langsung ke printer Bluetooth.
  • Mengirimkan laporan keuangan dan rekap omzet harian ke pemilik outlet.
  • Kami TIDAK PERNAH MENJUAL atau menyewakan data pribadi Anda atau pelanggan Anda kepada pihak ketiga manapun.

4. Penyimpanan Data & Hak Pengguna

Data transaksi disimpan secara lokal di perangkat Anda (IndexedDB / LocalStorage) dan dapat disinkronkan ke server cloud terenkripsi. Anda memiliki hak penuh untuk meminta penghapusan data bisnis Anda kapan saja dengan menghubungi kami.
